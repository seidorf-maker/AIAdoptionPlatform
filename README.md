# OnRamp

A role-based AI adoption platform that gives non-technical employees at
mid-to-large companies a sanctioned, job-specific path into using AI, and
issues real competence-based certifications — not completion badges.

Built as a course project (ISM6427 — AI for Innovation, Summer 2026) by
Meg Seidorf & Maritza Herbert.
